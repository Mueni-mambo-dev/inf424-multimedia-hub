## Project Overview
EduStream is a modern multimedia learning hub designed to demonstrate the integration of HTML5, CSS, and JavaScript for interactive learning experiences. The platform allows users to access educational content through video, audio, images, and interactive elements within a structured web interface.

This project focuses on multimedia integration, responsive design, and user experience in a web-based learning environment.

##  Objectives
The main objectives of this project are:
- To demonstrate the use of HTML5 multimedia elements (audio, video, images)
- To implement a responsive and user-friendly learning interface
- To apply JavaScript for interactivity and dynamic content control
- To showcase different media formats (JPEG, PNG, WebP, AVIF)
- To simulate a real-world e-learning platform

## Features
-  Embedded HTML5 video player with custom controls
-  Audio playback for learning materials and lectures
-  Optimized images in multiple formats (JPEG, PNG, WebP, AVIF)
-  Responsive layout for mobile and desktop users
-  JavaScript-powered interactivity (play, pause, navigation)
-  Structured learning sections and content organization
-  Clean and modern UI design

##  Technologies Used
- HTML5 – Structure and multimedia embedding
- CSS3 – Styling and responsive design
- JavaScript (Vanilla JS) – Interactivity and DOM manipulation
- Media formats: MP4, MP3, JPEG, PNG, WebP, AVIF
